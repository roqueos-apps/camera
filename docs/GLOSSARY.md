# Glossary

_[Português](pt-BR/GLOSSARIO.md) | English_

> **For whom:** whoever meets a word in the code, a commit or a conversation and needs to know what it means here.
> **What is here:** the terms as they appear in the code (many in Portuguese, since the code is), what each one is, and where it lives.
> **Where to go for the rest:** how the pieces fit, [ARCHITECTURE.md](ARCHITECTURE.md); the exact values, [REFERENCE.md](REFERENCE.md).

| Term                                   | What it is                                                                                                              | Where                                                                         |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `sistema`                              | the object RoqueOS (or the dev or fake system) hands to `montar`: everything the app gets from RoqueOS comes through it | [`src/index.js`](../src/index.js), `@roqueos-apps/app-sdk`                    |
| `definirApp`                           | the SDK function that turns `{ id, capacidades, montar }` into the object RoqueOS mounts (`mount`)                      | [`src/index.js`](../src/index.js)                                             |
| `montar` / `mount`                     | `montar(el, sistema, { ativo })` is what the app writes; `mount` is what RoqueOS calls, after the SDK checks the system | [`src/index.js`](../src/index.js)                                             |
| capability (`capacidade`)              | an optional part of the `sistema` the app must declare; the Camera declares only `arquivos`                             | [`app.json`](../app.json), `CAPACIDADES` in [`src/index.js`](../src/index.js) |
| `arquivos`                             | the capability for the person's Files: `salvar` and `abrirPasta`                                                        | [`src/Camera.vue`](../src/Camera.vue)                                         |
| `Imagens`                              | the Pictures folder in Files; the only folder in `pastas`, where captures go                                            | [`app.json`](../app.json)                                                     |
| `sem-conta`                            | the error code the system returns when nobody is signed in; the app shows `semConta` and keeps the capture              | [`src/Camera.vue`](../src/Camera.vue)                                         |
| light profile (`modoLeve`, `leve`)     | the profile for weak devices: no animated mesh, no blur, countdown without pulse; read once at open                     | [`src/index.js`](../src/index.js), [`src/camera.scss`](../src/camera.scss)    |
| engine (`motor`, `useCamera`)          | the composable that owns the `MediaStream`, capture, zoom, torch and video                                              | [`src/useCamera.js`](../src/useCamera.js)                                     |
| screen (`tela`)                        | the Vue component with viewfinder, controls and settings                                                                | [`src/Camera.vue`](../src/Camera.vue)                                         |
| viewfinder (`visor`)                   | the area with the live image, the framing aids and the state messages                                                   | [`src/Camera.vue`](../src/Camera.vue)                                         |
| shutter (`disparador`)                 | the main button: takes a photo (after the timer) or starts and stops a video                                            | [`src/Camera.vue`](../src/Camera.vue)                                         |
| CSS zoom (`cssZoom`)                   | zoom by cropping the centre, for devices without native `zoom`; the same crop goes into the photo                       | [`src/useCamera.js`](../src/useCamera.js)                                     |
| aspect (`aspect`, proporção)           | full, 1:1, 4:3 or 16:9, applied as a crop at capture and shown as a mask                                                | [`src/useCamera.js`](../src/useCamera.js)                                     |
| grid (`grade`)                         | `none`, `thirds` (rule of thirds) or `phi` (golden ratio), drawn over the live image                                    | [`src/Camera.vue`](../src/Camera.vue)                                         |
| level (`nível`)                        | the horizon indicator from `DeviceOrientation` `gamma`                                                                  | [`src/Camera.vue`](../src/Camera.vue)                                         |
| `photo_capture`                        | the metric event sent once per photo taken, the same name as before the move                                            | [`src/Camera.vue`](../src/Camera.vue)                                         |
| `app check`                            | the SDK command that checks the repository against the RoqueOS contract                                                 | `yarn app:check`                                                              |
| `yarn verificar`                       | the gate: lint, format, tests and `app check`                                                                           | [`package.json`](../package.json)                                             |
| `paridade.json`                        | the inventory of features from before the move and what happened to each one                                            | [`paridade.json`](../paridade.json)                                           |
| fake window (`janela falsa`)           | the SDK's development system, which draws a RoqueOS window around the app for `yarn dev`                                | [`dev/main.js`](../dev/main.js)                                               |
| fake system (`sistema falso`)          | the SDK's test system, with in-memory Files and recorded calls                                                          | [`test/app.spec.js`](../test/app.spec.js)                                     |
| `Ros*`                                 | the primitives of the UI kit: `RosBotao`, `RosFolha`, `RosIcone`, `RosInterruptor`, `RosVazio`                          | `@roqueos-apps/ui`                                                            |
| `--camera-*`                           | the app's own CSS variables; `--ros-*` belongs to the system                                                            | [`src/camera.scss`](../src/camera.scss)                                       |
| move out of the core (saída do núcleo) | 28/09/2026, Goal 28, Wave 4: the Camera left the closed RoqueOS for this repository                                     | [README.md](../README.md)                                                     |
| `primeira-parte`                       | the `camada` (layer) of a first-party app in `app.json`                                                                 | [`app.json`](../app.json)                                                     |
| Finder                                 | the RoqueOS file manager, which the gallery button opens on Pictures                                                    | [`src/Camera.vue`](../src/Camera.vue)                                         |
| DCO                                    | Developer Certificate of Origin: the `Signed-off-by` line every commit carries                                          | [`.github/workflows/dco.yml`](../.github/workflows/dco.yml)                   |
