# Glossário

_Português | [English](../GLOSSARY.md)_

> **Para quem:** quem encontra uma palavra no código, num commit ou numa conversa e precisa saber o que ela quer dizer aqui.
> **O que tem aqui:** os termos como aparecem no código (muitos em português, porque o código é), o que cada um é, e onde mora.
> **Onde ir para o resto:** como as peças se encaixam, [ARQUITETURA.md](ARQUITETURA.md); os valores exatos, [REFERENCIA.md](REFERENCIA.md).

| Termo                            | O que é                                                                                                                                  | Onde                                                                                |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `sistema`                        | o objeto que o RoqueOS (ou o sistema de desenvolvimento, ou o falso) entrega ao `montar`: tudo o que o app recebe do RoqueOS vem por ele | [`src/index.js`](../../src/index.js), `@roqueos-apps/app-sdk`                       |
| `definirApp`                     | a função do SDK que transforma `{ id, capacidades, montar }` no objeto que o RoqueOS monta (`mount`)                                     | [`src/index.js`](../../src/index.js)                                                |
| `montar` / `mount`               | `montar(el, sistema, { ativo })` é o que o app escreve; `mount` é o que o RoqueOS chama, depois de o SDK conferir o sistema              | [`src/index.js`](../../src/index.js)                                                |
| capacidade                       | uma parte opcional do `sistema` que o app precisa declarar; a Câmera declara só `arquivos`                                               | [`app.json`](../../app.json), `CAPACIDADES` no [`src/index.js`](../../src/index.js) |
| `arquivos`                       | a capacidade dos Arquivos da pessoa: `salvar` e `abrirPasta`                                                                             | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| `Imagens`                        | a pasta Imagens dos Arquivos; a única em `pastas`, para onde vão as capturas                                                             | [`app.json`](../../app.json)                                                        |
| `sem-conta`                      | o código de erro que o sistema devolve quando ninguém entrou; o app mostra o `semConta` e mantém a captura                               | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| perfil leve (`modoLeve`, `leve`) | o perfil do aparelho fraco: sem a malha animada, sem desfoque, contagem sem pulsar; lido uma vez ao abrir                                | [`src/index.js`](../../src/index.js), [`src/camera.scss`](../../src/camera.scss)    |
| motor (`useCamera`)              | o composable dono do `MediaStream`, da captura, do zoom, da lanterna e do vídeo                                                          | [`src/useCamera.js`](../../src/useCamera.js)                                        |
| tela                             | o componente Vue com o visor, os controles e os ajustes                                                                                  | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| visor                            | a área com a imagem ao vivo, as ajudas de enquadramento e as mensagens de estado                                                         | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| disparador                       | o botão principal: tira a foto (depois do temporizador) ou começa e para o vídeo                                                         | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| zoom por CSS (`cssZoom`)         | zoom recortando o centro, para aparelho sem `zoom` nativo; o mesmo recorte vai para a foto                                               | [`src/useCamera.js`](../../src/useCamera.js)                                        |
| proporção (`aspect`)             | cheia, 1:1, 4:3 ou 16:9, aplicada como recorte na captura e mostrada como máscara                                                        | [`src/useCamera.js`](../../src/useCamera.js)                                        |
| grade                            | `none`, `thirds` (regra dos terços) ou `phi` (proporção áurea), desenhada sobre a imagem ao vivo                                         | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| nível                            | o indicador de horizonte a partir do `gamma` do `DeviceOrientation`                                                                      | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| `photo_capture`                  | o evento de métrica mandado uma vez por foto tirada, o mesmo nome de antes da saída                                                      | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| `app check`                      | o comando do SDK que confere o repositório contra o contrato do RoqueOS                                                                  | `yarn app:check`                                                                    |
| `yarn verificar`                 | o gate: lint, formato, testes e `app check`                                                                                              | [`package.json`](../../package.json)                                                |
| `paridade.json`                  | o inventário das funcionalidades de antes da saída e do que aconteceu com cada uma                                                       | [`paridade.json`](../../paridade.json)                                              |
| janela falsa                     | o sistema de desenvolvimento do SDK, que desenha uma janela do RoqueOS em volta do app no `yarn dev`                                     | [`dev/main.js`](../../dev/main.js)                                                  |
| sistema falso                    | o sistema de teste do SDK, com Arquivos em memória e o registro das chamadas                                                             | [`test/app.spec.js`](../../test/app.spec.js)                                        |
| `Ros*`                           | os primitivos do kit de interface: `RosBotao`, `RosFolha`, `RosIcone`, `RosInterruptor`, `RosVazio`                                      | `@roqueos-apps/ui`                                                                  |
| `--camera-*`                     | as variáveis CSS do próprio app; `--ros-*` é do sistema                                                                                  | [`src/camera.scss`](../../src/camera.scss)                                          |
| saída do núcleo                  | 28/09/2026, Goal 28, Onda 4: a Câmera saiu do RoqueOS fechado para este repositório                                                      | [README.pt-BR.md](../../README.pt-BR.md)                                            |
| `primeira-parte`                 | a `camada` de um app de primeira parte no `app.json`                                                                                     | [`app.json`](../../app.json)                                                        |
| Finder                           | o gerenciador de arquivos do RoqueOS, que o botão da galeria abre nas Imagens                                                            | [`src/Camera.vue`](../../src/Camera.vue)                                            |
| DCO                              | Developer Certificate of Origin: a linha `Signed-off-by` que todo commit leva                                                            | [`.github/workflows/dco.yml`](../../.github/workflows/dco.yml)                      |
